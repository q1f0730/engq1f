# 四级单词打卡 · 更新日志

## v7.0.0 · 坚持与打卡（2026-10-13）
- 补卡：打卡后连续天数到 7 的倍数奖励 1 张补卡（最多 3 张，同一天只发一次，打卡提示里会说）；昨天漏打卡（且不是休息日）时今日页出现「昨天漏打卡了」卡片，预览补上后的连续天数，一键用 1 张补上昨天；补出来的天在周条和月历里标「补」，当日回看显示「补卡」。补卡数在今日页打卡卡片底部和「我的 → 坚持与打卡」显示，随备份导出。
- 休息日：「我的」可设每周一天（无 / 一…日）；没打卡的休息日不断也不计入连续，最长连续和「连续 N 天」成就同样认休息日；休息日不能补卡，当天今日页显示「今天是休息日」提示（学了照样能打卡），周条显示「休」，月历空白的休息日标「休」。
- 时长目标：打卡标准可选「完成新词和复习」（原规则）或「学够时长」10 / 20 / 30 分钟（按当天作答累计用时，每题最多计 1 分钟）；时长模式下今日主卡片显示「今日学习 N / 20 分钟」和进度环，打卡卡片换成时长进度条，小结页显示今日用时。
- 学习提醒：「我的」打开开关时申请通知权限，默认 20:00，可改时间；应用开着或在后台存活时每 30 秒检查一次（切回前台也查），到点且当天没打卡就发一条通知（优先走 service worker 的 showNotification，安卓 Chrome 只认这个），每天最多一次；权限被拒时开关保持关闭并提示去浏览器设置。
- 应用角标：支持 Badging API 时在桌面图标上显示今天待复习数（按复习上限截断），复习清零或关闭开关时清除；切回前台时刷新。
- 系统分享：分享图支持 Web Share（文件分享）时主按钮变成「分享到微信 / QQ」，直接调起系统分享面板；用户取消不做任何事，分享失败或浏览器不支持时退回保存图片（并提示从相册发给好友）。
- 分享图模板：朱砂（原版）/ 纸笺（米色信笺、朱红「已打卡」印章、最近 7 天打卡格）/ 夜读（深蓝夜空、金色月牙、居中大字与 7 天小点）三款，分享面板顶部切换，选择会记住。
- 里程碑庆祝：打卡（或补卡）让连续天数跨过 7 / 30 / 100 天时弹全屏庆祝：彩纸飘落、奖章弹出、一句文案，伴随震动（受震动开关控制）；点按钮、点空白或 Esc 关闭，关闭后再弹分享图；系统开了「减少动态效果」时不放动画和彩纸。
- 断签预警：晚上 21 点后今天还没打卡（且不是休息日），今日页顶部出现红色提醒条：「连续 N 天要断了！」、离今天结束的倒计时（每 30 秒刷新）、还差几个新词 / 几个复习（时长模式显示还差几分钟），按钮直接去学；任务已完成时变成「打卡」。
- 当日回看：统计页的月历格子和热力图格子都可以点（未来的不能点），弹出当天的打卡状态（已打卡 / 补卡 / 休息日 / 未打卡）、新学 / 复习 / 正确率 / 用时，以及当天新学的词（按学习顺序）和复习的词（带当天最后一次评分），点词看详情，关掉详情回到当天。数据来自 v6 的复习日志，更早的日子用卡片的首学日期补出新学。
- 「我的」新增「坚持与打卡」面板；版本号 7.0.0。
- 测试：vitest 190 个（新增 src/lib/v7.test.ts 32 个：休息日连续 / 最长连续、补卡发放与使用、里程碑、时长打卡、提醒与角标判定、断签预警、当日回看、Web Share 回退、备份字段校验、store 往返）；e2e 共 399 项检查，新增 v7 段 76 项（通知 / 角标 / Web Share 用桩替身，断签预警用 Playwright 固定时钟到 21:30 / 20:30 验证）。
- 已知限制：没有后端推送，学习提醒只有在应用开着或后台还没被系统杀掉时才会发；角标只在支持 Badging API 的已安装 PWA 上显示（浏览器不支持时开关置灰，不少安卓浏览器还不支持）；时长只算答题用时，磁带模式的收听时间不计入；改了休息日后，过去的连续天数也按新的休息日重算。

## v5.0.0 · 词库与词单管理（2026-10-13）
- 自定义词单：词库新增「词单」标签页，新建时起名（空名自动「词单 N」，最多 20 字、50 个词单），可顺带导入生词本；卡片显示词数、未学 / 学习中 / 已掌握、到期数与进度条；单词详情「加入词单」逐个词单开关（显示已在几个词单），也能在这里直接新建；词单页可重命名、删除（可撤销）、「导入生词本 N」。词单随备份导出 / 导入（导入时校验并去重）。
- 词单学习（/study?mode=list&list=id）：先复习词单里到期的词（最早到期优先，最多 20），没有到期就按词单顺序学 10 个新词（跳过「明天再说」中的），都学过了就随机 20 个按提前复习排期巩固（间隔不会变短），全斩了显示完成；入口按钮写明下一步（复习到期 N 词 / 学 N 个新词 / 提前巩固 N 词），小结页「继续词单」。

- 字母索引：列表右侧 A–Z 索引条，点或按住滑动跳到对应字母，中间显示大字母提示；没词的字母变灰，缺的字母跳到后面最近的一个；不是按字母排序时第一次点会自动切到「按字母」，按字母排序时列表出现字母分组头。

- 词性筛选：n. / v. / adj. / adv.，看词的所有释义行（vt/vi 归为 v.，n&v 这类拆开算），不只看第一条。
- 仅看核心词：工具栏开关，和状态、词性、搜索、排序叠加。

## v4.0.0 · 四级备考冲刺（2026-10-13）
- 考试倒计时：今日页新增「备考」卡片，显示距四级考试天数与日期；默认取下一场（2026-06-13 / 2026-12-12 按中国教育考试网公告标「官方」，未公布场次按 6/12 月第二个周六预估标「预估」）；「我的 → 四级考试」可选接下来两场或自定义日期，自定义日期过了自动切到下一场。
- 冲刺计划：按剩余新词与考试日期算每日新词（>30 天留最后 14 天只复习，10–30 天留三分之一），向上取到每日新词档位，显示学完日期；今日页「应用」/「我的」「一键应用」直接改每日新词；最高档 100 也来不及时提示改学核心词。
- 模拟小测（新页面 /quiz）：20 题、限时 5 分钟，8 种题型按固定配比混排（英选中 3 / 中选英 3 / 听音选义 2 / 听音辨词 2 / 短语选义 2 / 一词多义 3 / 词性判断 2 / 短语挖空 3）；学过的词优先（错过的更优先，最多 12 个），其余从当前词书补；中途不显示对错，可跳过；最后 1 分钟计时变红，按绝对时间计，超时自动交卷、未答算错；结果页给分数、答对数、用时和「比上次」。小测不改复习计划。
- 小测错题回顾：结果页默认列出错题（可切到全部 20 题），每题显示「你的答案 → 正确答案」，展开看完整释义、听发音、单独加入生词本；「错题加入生词本 N」一键全加。
- 小测历史：每次成绩存本机（最多 60 次，随备份导出/导入），统计页新增「模拟小测成绩」：最近 / 平均 / 最高 / 次数 + 最近 20 次成绩曲线（虚线 60 分）。
- 一词多义题：给出单词，从 4 个释义里选出「不属于」它的；只给有 ≥3 个义项的词出题，干扰释义取同词性、长度和「的/地」词尾相近、与本词义项不重字的别的词。
- 词性判断题：给出单词，选 n. / v. / adj. / adv.；只给全部释义都属于同一个词性的词出题（vt/vi 归为 v.，n&v 这类多词性词不出），避免争议。
- 短语挖空题：常用短语里本词换成空格并给中文提示，从 4 个英文词里选；干扰项同词性、长度相近、不是本词变形、不出现在短语里，只选纯小写词（排除专有名词）。
- 三种新题型也进入日常复习：落在「回想」的词有一半换成它能出的新题型（不影响原有的英选中/中选英/听音/短语/听音辨词分配）。
- 核心未掌握清单：词库新增「核心未掌握」标签页（未学 + 学习中的核心词），显示未学 / 学习中 / 已掌握与进度条，「学 10 个未学核心词」直接开始（都学过时改为复习学习中的核心词，最早到期优先）；今日页备考卡片有入口。
- 今日小测提醒：当天没做小测时今日页显示「今日小测」入口卡片，做完当天隐藏，第二天再出现。
- 「我的」版本号 4.0.0。
- 测试：vitest 117 个（新增 src/lib/v4.test.ts 35 个）；e2e 新增 v4 段 52 项（超时交卷用 Playwright clock 快进验证）。

- 提前复习：今日复习清零后可提前复习明天到期的词，新间隔按实际经过天数计算且不短于原间隔。
- 每日复习上限：不限/50/100/200，超出部分顺延，今日待复习与打卡判定按上限计。
- 明天再说（B）：当前词推到明天，不计对错、不进错词本，可撤销；新词搁置到明天。
- 形近词辨析：卡片背面和单词详情列出最多 3 个拼写相近的词（相邻对调算一步；≤6 字母差 1 步，更长差 2 步），标出不同字母；详情中可跳转并返回。
- 顽固词：遗忘 ≥3 次标「顽固」，词库新增「顽固词」标签页与专项复习，今日页有入口。
- 短语选义题：有合适短语（含本词、中文干净）的词多一种复习题型，短语中文去掉词性前缀、最多两个义项。
- 震动反馈：答对 12ms、模糊 28ms、答错 30-50-30ms，可在「我的」关闭。
- 数据安全：启动时申请持久化存储；「我的」显示存储状态与上次备份日期；≥10 条记录且 7 天未备份时今日页提醒（可稍后 3 天）。
