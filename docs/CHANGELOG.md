# 四级单词打卡 · 更新日志

## v9.0.0 · 更多玩法（2026-10-13）
- 配对消消乐（新页面 /match，今日页「配对消消乐」入口）：左英文右中文各 5 块，先点哪边都行，配对成功两块一起消掉，一轮清空马上换下一轮；限时 60 秒（按绝对时间，最后 10 秒变红），配对 +10、从第 2 个连对起每对再 +2（最多 +8）、配错 −5（不低于 0）并清零连对；结果页给得分、消掉对数、配错次数、最高连对、是否新纪录，配错的词可一键进生词本。学过的词够 20 个就只用学过的（到期、忘过的优先），不够用词书接下来的词补。
- 判断对错（新页面 /judge，今日页入口）：20 题，每题一个单词配一个释义，一半是它自己的、一半换成同词性别的词且意思不重叠的释义；右滑 / → / 「对」，左滑 / ← / 「不对」，跟随「滑动方向」设置交换；答对 0.65 秒后自动下一题，答错显示它真正的意思和那条释义属于谁，点「继续」再走；满分 100，记最高分。
- 小游戏只练不排期：不改复习计划、不写复习日志，只把最高分存进备份（gameBest）；今日页「碎片时间」改成 2×2：磁带模式 / 速刷 / 配对消消乐 / 判断对错，有纪录后显示最高分。
- 同义词组（新页面 /syn，词库页右上角「同义词组」入口，底栏仍高亮「词库」）：同词性、有一个义项完全相同的词聚成一组（如「v. 放弃」：quit / resign / yield / abandon / compromise / surrender），义项去掉括号说明和 [医] 之类的领域标记、只留 2–8 字，去掉只差词尾的同族词，每组最多 12 个；共 2000+ 组，按词数排序，可搜中文义项或英文单词，词块按 未学 / 学习中 / 已掌握 着色，点开看详情。
- 单词详情新增「同义词 · 意思相同」：列出本词所在的组（按释义顺序，最多 4 组），点词跳转、可返回，「全部同义词组」跳到同义词组页并搜好这个义项。
- 同根形词：单词详情新增「同根形词 · 共享前缀」，列出和本词共享 ≥5 个字母前缀的词（共同前缀长的在前，最多 12 个，nation → national / nationality），共享部分灰色、不同部分高亮，附一条释义，点开跳转。同义词与同根形词这块是懒加载的，不占首屏。
- 新词预习（「我的 → 复习题型 → 新词预习」，默认关）：开始一组新词前先列出这 10 个词（音标、释义、点喇叭发音），认识的点「斩」（可取消），「开始学习 N 词」只学剩下的；斩掉的词记为已斩、按新词首答「认识」计入今日新学和复习日志（与学习中斩一致）；整组都斩掉就自动换下一组继续预习。
- 学后速测：每组新词学完，小结页出现「学后速测 N 题」，点开把这组（去掉斩掉的）英选中四选一过一遍；结果计入小结（「学后速测 9/10 · 90%」、没记住的词、每个词旁标 速测✓/✗），速测答错的词也并入「错词再练」；不改复习计划。「我的」打开「学后速测」后学完自动开始，左上角可跳过。
- 例句选词：新复习题型，用已经缓存的在线例句把本词（含 -s/-ed/-ing 等变形，只认整词）挖空，从 4 个英文词里选；干扰项同词性、长度相近、不是本词变形、不在句子里出现；答完还原整句并高亮。只有本机缓存过这个词的例句才出（不额外联网）。
- 自选题型：「我的」新增「复习题型」面板，11 种题型（回想 / 英选中 / 中选英 / 听音选义 / 听音辨词 / 短语选义 / 中选短语 / 一词多义 / 词性判断 / 短语挖空 / 例句选词）可逐个开关；关掉的题型在复习、提前复习、词本复习、错词再练里都不再出现（落到关掉的题型时换成这个词能出的其他开着的题型）；至少保留一种基础题型（回想 / 英选中 / 中选英 / 听音选义），关最后一个会提示并拒绝。全部开着时与 v8 的分配完全一致。
- 难度递进题型（「我的」开关，默认关）：按当前间隔出题，≤3 天英选中、4–9 天中选英、≥10 天听音（有形近词时听音辨词，否则听音选义）；对应题型被关掉时退回普通分配；没学过的词（如生词本里未学的）不递进。
- 中选短语：新复习题型，给出常用短语的中文（去掉领域标记），从 4 个英文短语里选；干扰短语来自同词性的别的词、中文互不相同；答完每个选项下显示它的中文，题干还原英文短语并高亮本词。只给有合适短语的词出。
- 「我的」版本号 9.0.0。
- 测试：vitest 288 个（新增 src/lib/v9.test.ts 42 个：配对出题与计分、判断对错出题与滑动、同义词组与搜索、同根形词、预习斩词入账、速测小结与错词合并、例句挖空与选项、自选题型约束与「永不出关掉的题型」、难度递进分档、中选短语选项、旧备份兼容）；e2e 共 581 项检查，新增 v9 段 106 项（限时用 Playwright clock 快进，滑动用 touch PointerEvent，例句选词用预置的例句缓存）。
- 已知限制：同义词组按「义项文字完全相同」聚合，词表释义粒度不一，偶尔会把只在某个义项上相同的词放在一组；同根形词只看拼写前缀，会混进 concern / concert 这类形似但不同根的词（界面标「共享前缀」）；例句选词依赖在线例句缓存，没联网看过例句的词不会出这种题。

## v7.0.0 · 坚持与打卡（2026-10-13）
- 补卡：打卡后连续天数到 7 的倍数奖励 1 张补卡（最多 3 张，同一天只发一次，打卡提示里会说）；昨天漏打卡（且不是休息日）时今日页出现「昨天漏打卡了」卡片，预览补上后的连续天数，一键用 1 张补上昨天；补出来的天在周条和月历里标「补」，当日回看显示「补卡」。补卡数在今日页打卡卡片底部和「我的 → 坚持与打卡」显示，随备份导出。
