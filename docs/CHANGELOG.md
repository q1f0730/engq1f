# 四级单词打卡 · 更新日志

## v11.2.0 · Jobs 评审第 2 轮修复（2026-10-14）
评审 r2 给了 6/10：r1 的 28 条复查通过、3 条没过，新列出 16 条（P1 × 6，P2 × 10）。这一版全部修完，重点是考试临近、落后、离开一阵子回来这几种状态下 app 不再自相矛盾。
- 统计：「近 7 天记得住 5400%」——保持率被乘了两次 100。百分比统一由 `fmtPct`（0–1 小数 → 0–100%，夹在范围内）格式化；变化写成「百分点」；四格主数字 390 宽下不截断。
- 恢复期：主卡只有「复习 N」一个主按钮，大数字是「已复习 x / 今天 N」；新词入口改成「提前恢复新词」（先确认，确认后结束恢复计划），直接打开学新词的链接也不会偷偷开一组新词。漏了一天时，剩下的积压从今天起按额度重新摊开、顺延结束日（「漏了一天，已顺延到 M/D」），每天的量守住额度。
- 计划：引导、首页冲刺卡、「我的」用同一个计划引擎。每天 100 个也学不完时直接说实话（「N 天学不完 X 个，每天 100 个考前能先拿下 Y 个」），选项写「考前学 N 个」；考试今天 / 明天进入考前模式（只复习、不报学完日期）；引导保存后首页不再冒出第二张计划卡。每日新词已经是上限时只给一张能关掉的信息卡（关掉后这一场不再出现）；有按钮的建议按下去状态一定变，一次加量最多翻倍；全部词每天要 >50 个时先提「改学核心词」。
- 考试日期：考完（自定日期过了，或自动场次考后 30 天内、考前在学）先问「四级考完了 · 备考下一场 / 先休息」，选了才换计划；考试当天不出恢复计划；「我的」不收过去的日期（日期框 `min=今天`，选了给提示）。
- 首页：断签提醒并进主卡顶部（21 点后、任务真没完成、真有连续天数才出现），不再是单独的红色横幅；任务完成后主卡的主按钮就是「打卡」，当天不劝加量；不急的建议排到第一屏以下、同一时间最多一张。文案：复习为 0 时「还剩」一行不多一个点；什么都没做的项目不打勾；新用户没有补卡说明；没有到期复习时不放速刷入口。第一组完成的「这些词什么时候回来」按真实到期日写。
- 离线 / 发新版：代码块加载失败显示「网络不好，页面没加载出来 · 重试」，不再说「记录 app 读不懂」、不出回滚按钮；SW 预缓存所有懒加载代码块，缓存匹配忽略 `Vary`（之前带 `Vary: Origin` 的服务器上离线时所有子页面打不开）；首页空闲时预取常用页面。
- 救援页：「从头开始」先把原始数据下载成文件，再在本机留一份；数据中心新增「救援时另存的原始数据」（导出 / 恢复 / 删除）；没有快照时不提回滚。
- 返回键：× 退出退回 history（不再多一条要白按的首页）；深链打开的学习页退出后再按返回不会重进学习页；确认框开着时返回 = 继续；引导每一步可以用返回回到上一步；已完成引导的人打开 `#/welcome` 直接回首页、计划不动。
- 多窗口：日志按差值合并，同一个新词在两个窗口里只算一次；别的窗口清空 / 覆盖导入 / 回滚后，这边正在学的一组直接结束，不再往新档案里写。
- 「我的」：「高级」改成二级页（≤ 2 屏，打卡规则 / 学习偏好 / 复习题型 / 字号与无障碍默认折叠）；7 个算法开关搬进三级页「算法实验室」；「清空所有学习记录」挪到数据中心最底部。
- 引导：三屏不再有署名（只在「我的 → 关于」）；去掉「学习顺序」这一步（在「高级 → 词书与顺序」）。单词详情美 / 英音标一样时只写一行。
- 测试：vitest 398 个（新增 src/lib/v11_2.test.ts 21 个）；e2e 全量 918 项检查全绿（jobs-r2 段 83 项，每项对应评审条目；jobs-r1 段 95 项）。旧用例按新设计更新：引导没有学习顺序、过期的自定考试日期先问再换、「高级」是二级页且题型折叠、全部词考前学不完时引导预览说「考前能学 N 个」；主流程改为和其他套件一样出错不中断全量跑。首屏 JS（gzip）198.6 KB（上限 200 KB）。
- 修复记录（每条怎么修、怎么验证）见评审工作区的 fixes-r2.md。

## v11.1.0 · Jobs 评审第 1 轮修复（2026-10-13）
发布前评审 r1 列出 31 条（P0 × 2，P1 × 11，P2 × 18），全部修完；首页只回答「现在该干嘛」，设置页砍到 8 项，坏文件和多窗口不再丢记录。
- 数据安全（P0）：
  - 导入备份逐条校验：日期必须是 YYYY-MM-DD、间隔 / 系数 / 次数是有限数、状态在枚举里、单词必须在词库；能修的修、修不了的丢，对比弹窗写明丢了 / 修了多少条。读档、导入、多窗口同步都走同一套校验，坏字段不再进界面。
  - 救援页：存档读不出来或界面崩了，显示独立于主界面的救援页——「回滚到最近快照」（回滚后回首页）、「导出原始数据」、「从头开始（原始数据另存一份）」；在救援页上不会覆盖原始数据。
  - 多窗口：写入前比对存储，被别的窗口改过就三方合并再写；`storage` 事件 + BroadcastChannel 即时同步，并提示「另一个窗口…已同步 / 已合并」。
  - 来自更新版本的备份直接拒绝（「请先更新 app」）；备份词数为 0 或不到本机一半时「覆盖」变红、要再点一次确认，默认主按钮是「合并」。
- 返回键：每个底部弹层打开时压一条 history，Android 返回手势 / 浏览器返回只关最上面的弹层；按钮关掉的弹层条目自动跳过。学习、配对消消乐、判断对错、小测进行中按返回（或 ×、Esc、底部标签）先确认「退出本组？ / 退出这一局？ / 交卷还是放弃」，确认退出才回上一页；一组学完、交卷后返回直接离开，不再弹确认。
- 计划：新手引导第 1 步先问考试（默认 2026-12-12），按「考前 ≥14 天学完」推荐词书和每日量（60 天 → 核心词每天 60 个），每个选项标「考前 X 天学完 / 考后才学完」；首页、冲刺卡、「我的」用同一个计划引擎，冲刺卡标题写真正算出来的每日量，来不及时直接「改学核心词（每天 X 个）」；减新词的建议不会低于考试计划需要的量。
- 首页：主卡只有一个主动作 + 一行「还剩…约 X 分钟」；建议排一个队，同一时间最多一张（欢迎回来 / 恢复进度 → 补卡 → 备份 → 冲刺 → 减新词 → 安装 → 周报 → 顽固词 → 提前复习 → 今日小测）；游戏、今日一词、预测收进「更多练习」；考试倒计时和词书进度合成一张。断签预警只在真有连续天数可断时出现，欢迎回来 / 恢复期间不出现。打卡后就地庆祝，不再自动弹分享图；连点只算一次。
- 回归：隔了 ≥7 天、积压一大堆时只显示「欢迎回来」+ 一键恢复（积压按每天 ≤ 复习上限、最多 150 分几天清完，这几天新词暂停），恢复期间只显示进度。
- 「我的」：顶层只留考试日期、每日新词、复习上限、提醒、发音、外观、数据与备份、关于；词书顺序、打卡规则、题型（改成「智能 / 只用回想」）、记忆算法、无障碍、词汇量测试、清空收进「高级」。备份状态写成一句话。
- 文案与细节：欢迎页不再拿竞品当卖点、不写「十分钟」；算法页第一句讲人话，不出现 SM-2 / ease；「不联网 · 记录只存在这台手机上」；「斩」= 我本来就会（词库「已斩」），「已掌握」= 靠复习达到；第一组完成有「第一组 ✓」，连续 0 天时显示还差几个能打卡；学到一半刷新提示「刚才学的 N 个已保存」；时间预估新用户按新词 15 秒、复习 8 秒。
- 学习页：顶栏只留 × 和进度，撤销 / 明天再说 / 收藏放到卡片下面带文字；卡片背面内容垂直居中；横屏（高度 < 500）题目和选项左右并排；键盘提示、快捷键入口只在有鼠标 / 触控板且没有触摸屏的设备显示（快捷键照样能用）。

## v11.0.0 · 数据与多设备（无云）+ 发布准备（2026-10-13）
- 数据中心（新页面 /data，「我的 → 数据」里的「数据中心」入口，底栏仍高亮「我的」）：备份与恢复、自动快照、学习报告图、导入词表、学习档案、数据体检、存储管理集中在一页，手机单列、桌面两列。
- 合并导入：导入备份（文件 / 剪贴板，「我的」和数据中心都一样）时，如果这台设备已有学习记录，先弹出对比（备份 vs 这台设备：词数、打卡天数、导出日期）再选「合并两台设备的记录」或「覆盖这台设备」；空设备直接恢复。合并规则：每个词取最近复习日更晚的那份（同一天看复习日志里最后一次作答时间，再看作答次数，都一样留本机）；复习日志按「词 + 时间 + 评分」去重后按时间合并；同一天的学习量取各项最大值；打卡、补卡日、生词本、明天再说取并集；词单同 id 或同名的合并词、其余追加；成就取更早的解锁日期；小游戏取最高分；设置、主题、档案保持本机。同一份备份合并两次结果不变（幂等）。合并后提示「已合并：新增 N 词，更新 M 词」。
- 自动快照：每天第一次打开应用（或切回前台）约 2.5 秒后在 IndexedDB 里存一份完整备份，每个档案保留最近 7 份；导入 / 合并前自动先存一份「导入前」快照，也可以「现在存一份」。列表显示时间、类型（每日自动 / 导入前 / 手动）、词数和大小，点「回滚」确认后整体恢复。快照代码按需加载，不进首屏。
- 加密备份：备份口令（可选，至少 4 位）填了就用 PBKDF2-SHA256（15 万次）派生密钥、AES-GCM-256 加密，每次随机 salt / iv；文件里只有密文（名为「…-备份-加密-日期.json」）。导入时认出加密备份会先要口令，口令错或文件被改动提示「口令不对，或者备份被改动过」。
- 剪贴板备份：「复制到剪贴板」把备份（填了口令就是加密的）复制成文本，方便发到聊天 / 备忘录；「从剪贴板恢复」直接读剪贴板，浏览器不给读取权限或剪贴板为空时弹出手动粘贴框；之后同样走合并 / 覆盖。
- 学习报告图：生成 1080×2540 的长图——总进度（学过 / 总词数、进度条）、掌握分布（已掌握 / 已斩 / 学习中 / 未学，带百分比）、坚持（当前连续、最长连续、累计打卡）、近 30 天每日新学 / 复习柱状图、记忆质量（30 天保持率、累计作答、累计用时）、最难啃的 5 个词；可保存图片，支持时直接系统分享。
- 导入词表：粘贴文本或选择 CSV / TXT 文件，按行识别（有逗号 / Tab / 分号的行只看第一个含英文的格子，没有分隔符的行每个英文词都算），大小写不敏感（china → China）、去 BOM、去重，只保留词库收录的词并列出跳过的词；词单名默认取文件名，一键生成自定义词单并跳到词单页。
- 数据体检：检查词库里不存在的单词记录、损坏的卡片（ease / 间隔 / 日期 / 状态不对）、生词本和词单里的未知词、无效的「明天再说」、复习日志里的未知词、无效或重复的打卡日期、损坏的每日学习记录；按类列出数量和示例，「一键修复 N 处」后再查为 0。
- 存储管理：分别显示学习记录、复习日志、其他档案、例句缓存（词数）、自动快照（份数）、发音缓存（词数）、离线应用文件的占用和总计（带彩色占比条），以及浏览器配额和已用比例；例句缓存和发音缓存可一键清理（联网时会重新获取），学习记录不能在这里删。
- 多学习档案：最多 5 个档案，进度、打卡、设置、复习日志、快照互相独立；默认档案沿用原来的存储 key，老用户无感升级；新建档案后从引导页重新开始，切换档案整页重载；可重命名，非当前档案可删除（连同它的数据和快照）；有多个档案时「我的」和数据中心显示当前档案名，报告图上也带档案名。
- 词单链接：词单页新增「分享链接」，把词单名和词（最多 1000 个）用 deflate-raw 压缩、base64url 编码进 `#/list-link?d=…`，链接带当前部署路径，不经过任何服务器；对方打开（没用过本应用也行，不会被引导页拦住）看到词单名、词数、自己学过几个和词表预览，「导入为我的词单」即可（同名自动另存）；链接损坏时友好提示。
