## v3.0.0 · 碎片时间与听力（2026-10-13）
- 磁带模式（新页面 /tape，今日页「碎片时间」入口）：自动连播「英文发音 → 停顿 → 中文释义语音 → 停顿」，列表循环；上一个 / 播放暂停 / 下一个，空格与 ←/→ 也可控制；不同词性的重复释义只读一次。
- 磁带范围：今日新词（今天还没学时预习接下来一天的新词）/ 到期复习 / 生词本 / 错词本 / 顽固词，显示数量，空的不可选；词库的词本页也有「磁带」按钮。
- 锁屏控制：接入 Media Session，锁屏显示当前单词和释义，耳机键 / 锁屏按钮可播放、暂停、上一个、下一个；播放时循环一段运行时生成的静音 WAV 保活（手机只为较长媒体显示锁屏控制）。
- 屏幕常亮：学习页和磁带模式申请 Screen Wake Lock，切回前台自动重新申请；「我的 → 屏幕常亮」可关闭。
- 发音语速：0.75× / 1× / 1.25×，同时作用于有道音频（playbackRate）和系统语音（1× = 0.9），「我的」和磁带页都能改。
- 重复遍数：磁带每词朗读 1 / 2 / 3 遍，界面显示「第 N/M 遍」。
- 定时停止：10 / 20 / 30 分钟，顶栏倒计时，按绝对时间判断（锁屏节流也不会多放）。
- 速刷模式（/study?mode=speed，今日页入口）：到期复习一屏一词、无翻转动画，点卡片原地展开释义，右滑 / → 认识，左滑 / ← 不认识；不认识的词本轮再来一遍，正常排期、记日志。
- 听音辨词题：新复习题型，播放发音后从 4 个拼写相近的英文中选出听到的词；只给有形近词的词出题，干扰项先取形近词、再补同首字母的近似拼写，排除同族变形和同音词（音标相同，如 site / cite）；答完每个选项下显示释义。
- 朗读例句：卡片背面和单词详情的每条在线例句旁有播放按钮（系统语音，跟随口音与语速）。

## v2.0.0 · 复习更聪明（2026-10-13）
- 间隔预览：认识/模糊/不认识按钮下显示下次复习时间，与算法一致。
- 本组错词再练：小结页「错词再练 N」，换成选择题再过一遍，不改复习计划、不记日志。
- 提前复习：今日复习清零后可提前复习明天到期的词，新间隔按实际经过天数计算且不短于原间隔。
- 每日复习上限：不限/50/100/200，超出部分顺延，今日待复习与打卡判定按上限计。
- 明天再说（B）：当前词推到明天，不计对错、不进错词本，可撤销；新词搁置到明天。
- 形近词辨析：卡片背面和单词详情列出最多 3 个拼写相近的词（相邻对调算一步；≤6 字母差 1 步，更长差 2 步），标出不同字母；详情中可跳转并返回。
- 顽固词：遗忘 ≥3 次标「顽固」，词库新增「顽固词」标签页与专项复习，今日页有入口。
- 短语选义题：有合适短语（含本词、中文干净）的词多一种复习题型，短语中文去掉词性前缀、最多两个义项。
- 震动反馈：答对 12ms、模糊 28ms、答错 30-50-30ms，可在「我的」关闭。
- 数据安全：启动时申请持久化存储；「我的」显示存储状态与上次备份日期；≥10 条记录且 7 天未备份时今日页提醒（可稍后 3 天）。
- 「我的」显示版本号（取自 package.json）。
- 测试：vitest 57 个（新增 src/lib/v2.test.ts 27 个）；e2e 120 项检查（新增 v2 段 38 项）。
