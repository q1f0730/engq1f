# 四级单词打卡 · 路线图 v2 – v11

作者 Q1f730 · 2026-10-13 · 目标用户：用 vivo 手机（Android Chrome / 系统浏览器）备考四级的大学生。

## 自我拷问（对照竞品 × 现有功能）

v1 已有：10 词一组 + 组内重学、SM-2 变体、斩、四种复习题型（回想/英选中/中选英/听音选义）、词书与每日新词计划、词汇量测试、打卡 + 热力图 + 分享图、生词本/错词本/熟词、词库搜索与详情、统计、深色模式、快捷键、离线 SW + 发音缓存、在线例句。

| 竞品 | 它强在哪 | 我们缺什么（只算离线可做、无打字、无账号） |
|---|---|---|
| 墨墨背单词 | 记忆算法可解释、复习负荷控制、形近词辨析、补签卡 | 按钮上看不到下次间隔；复习量爆了没有上限；没有形近词；没有补卡 |
| 不背单词 | 磁带模式（通勤听）、短语/语境、组内重学 | 不能免手听；短语只是展示，从不考 |
| 百词斩 | 斩、速刷、多题型、闯关感 | 没有速刷；题型偏少（无短语、无听音辨词、无配对） |
| 扇贝 | 词汇量测试、打卡分享、学习时长目标 | 只有新词数目标；分享只能下载图片 |
| 知米 | 听力模式、一词多义 | 不考多义、不考词性 |
| Anki | 提前复习、搁置（bury）、顽固卡（leech）、保持率统计、自定义学习 | 没有提前复习/搁置/顽固词；统计不看保持率 |
| 欧路 | 生词本分组、导出 CSV/Anki、打印 | 不能自建词单，不能导出给别的工具 |

结论：最先补「每天都用、马上见效」的复习质量（v2），再补通勤听（v3），然后是考试导向（v4），之后是管理、复盘、坚持、体验、玩法、算法、数据。

约束：数据只用现有词表（单词/音标/释义/短语/核心标记）+ 在线例句 + 浏览器 API；不做拼写/打字练习；不做账号和云。

## v2 · 复习更聪明 ✅ done (2026-10-13)
1. 间隔预览：认识/模糊/不认识按钮下显示下次复习时间（今天 / N 天 / N 个月），新词「认识」显示 2 天，与算法一致。
2. 本组错词再练：小结页出现「错词再练 N」，只含本组首答非「认识」的词，练习不改复习计划也不记日志。
3. 提前复习：到期清零且明天有到期词时，今日页显示「提前复习明天 N 词」，复习后这些词按提前复习重新排期（不早于原间隔）。
4. 每日复习上限：我的 → 每日复习上限（不限/50/100/200）；超出部分顺延，今日待复习数与打卡判定按上限计，并提示顺延数。
5. 明天再说（搁置）：学习页按 B 或点「明天再说」把当前词推到明天，不计对错、不进错词本，可撤销。
6. 形近词辨析：卡片背面与单词详情显示最多 3 个拼写相近的四级词（编辑距离 ≤2）及释义；详情里点它可跳转。
7. 顽固词：遗忘 ≥3 次的词标「顽固」，词库新增「顽固词」标签页并可专项复习，今日页有提示入口。
8. 短语选义题：复习题型新增「短语选义」——给出该词的常用短语，四选一中文；没有短语的词不出这种题。
9. 震动反馈：答对轻震、模糊一震、答错双震（navigator.vibrate），我的里可关闭。
10. 数据安全：启动时申请持久化存储；我的显示存储状态与上次备份日期；有学习记录且 7 天未备份时今日页提醒（可稍后）。

## v3 · 碎片时间与听力 ✅ done (2026-10-13)
1. 磁带模式：自动连播单词（英文发音 → 停顿 → 中文释义语音），可暂停/上一个/下一个。
2. 磁带范围：可选今日新词 / 到期复习 / 生词本 / 错词本 / 顽固词作为播放列表。
3. 锁屏控制：磁带模式接入 Media Session，锁屏显示当前单词，耳机键可切上/下一个。
4. 屏幕常亮：学习页和磁带模式开启 Wake Lock，可在设置里关闭。
5. 发音语速：0.75× / 1× / 1.25×，作用于有道音频与系统语音。
6. 重复遍数：磁带模式每词朗读 1 / 2 / 3 遍。
7. 定时停止：磁带模式 10 / 20 / 30 分钟后自动停止。
8. 速刷模式：一屏一词、无翻转动画，右滑认识左滑不认识，用于快速清复习。
9. 听音辨词题：播放发音，从 4 个拼写相近的英文中选出听到的词。
10. 朗读例句：卡片背面每条在线例句旁有播放按钮（系统语音）。

## v4 · 四级备考冲刺 ✅ done (2026-10-13)
1. 考试倒计时：设置考试日期（默认下一个 6 月/12 月考试日），今日页显示剩余天数。
2. 冲刺计划：按考试日期和剩余词数给出建议每日新词数，一键应用。
3. 模拟小测：20 题混合题型、限时 5 分钟，结束给分数与用时。
4. 小测错题回顾：小测结束可逐题查看正确答案，并一键加入生词本。
5. 小测历史：保存每次成绩，统计页显示成绩曲线。
6. 一词多义题：给出单词，选出「不属于」它的释义（仅多义词出题）。
7. 词性判断题：给出单词，选择它的主要词性（n./v./adj./adv.）。
8. 短语挖空题：短语中挖掉本词，四个英文词里选出正确的（选择，不打字）。
9. 核心未掌握清单：核心词中未学/学习中的词单独列出，可直接开始学习。
10. 今日小测提醒：当天未做小测时今日页显示入口卡片，做完后隐藏。

## v5 · 词库与词单管理 ✅ done (2026-10-13)
1. 自定义词单：新建命名词单，从词库/生词本添加或移除单词。
2. 词单学习：任意自定义词单可开始学习与复习。
3. 批量操作：词库长按进入多选，批量加入生词本 / 斩 / 重置。
4. 字母索引：词库右侧 A–Z 快速跳转条。
5. 词库排序：按字母 / 遗忘次数 / 下次复习 / 难度系数排序。
6. 词性筛选：按 n./v./adj./adv. 过滤词库。
7. 仅看核心词：词库开关，只显示核心词。
8. 导出 CSV：当前列表导出为「单词,音标,释义」CSV。
9. 导出 Anki：当前列表导出为 Anki 可导入的 TSV。
10. 打印词单：打印样式表三栏紧凑排版，可选隐藏释义做自测纸。

## v6 · 统计与复盘 ✅ done (2026-10-13)
1. 复习日志：每次作答记录日期与评分（本地），为后续统计提供数据。
2. 单词记忆轨迹：详情页显示该词每次复习的时间轴与评分。
3. 保持率曲线：近 30 天复习首答正确率曲线。
4. 学习时段分布：按小时统计作答量的柱状图。
5. 周报卡片：每周一今日页总结上周新学/复习/正确率/用时，并与前一周对比。
6. 月历视图：统计页可按月翻看打卡与每日学习量。
7. 难词榜：遗忘次数最多的 20 个词，可一键专项复习。
8. 间隔分布图：按 1/2–7/8–21/21+ 天分桶显示卡片数。
9. 30 天预测：未来 30 天每日复习量与预计掌握数。
10. 成就徽章：连续 7/30/100 天、学完 500/1000/全部词等，本地解锁并展示。

## v7 · 坚持与打卡 ✅ done (2026-10-13)
1. 补卡：每连续打卡 7 天获得 1 张补卡（上限 3），可补昨天。
2. 休息日：每周可设 1 天休息日，当天不打卡也不断连续。
3. 时长目标：可选按学习时长（10/20/30 分钟）判定打卡。
4. 学习提醒：设置提醒时间，应用打开或后台存活时到点发通知（Notification API）。
5. 应用角标：支持时用 Badging API 在图标上显示待复习数。
6. 系统分享：分享图优先用 Web Share API 直接分享到微信/QQ，不支持时下载。
7. 分享图模板：3 款打卡图样式可选。
8. 里程碑庆祝：连续天数达到 7/30/100 时全屏庆祝动画。
9. 断签预警：晚上 21 点后仍未打卡，今日页显示醒目提醒。
10. 当日回看：点击打卡日历某天，查看当天新学与复习的单词。

2. 字号调节：卡片与释义字号 小/中/大。
3. 左手模式：评分按钮顺序左右翻转。
4. 滑动方向交换：左滑/右滑含义可互换。
5. 专注模式：学习页一键全屏（Fullscreen API）。

10. 剩余时间估算：学习页显示本组按平均用时估算的剩余分钟数。

## v9 · 更多玩法
1. 配对消消乐：5 对英文-中文连线，限时计分。
2. 判断对错：单词 + 释义，判断是否匹配（左右滑作答）。
3. 同义词组：释义相同的四级词聚合展示（如「放弃」：abandon / desert …）。
4. 同根形词浏览：详情页列出共享 ≥5 字母前缀的词族。
5. 新词预习：开始一组新词前列表预览这 10 个词，可直接斩掉认识的。
6. 学后速测：每组新词学完立即一轮四选一检测，结果计入小结。
7. 例句选词：用已缓存的在线例句挖空本词，四选一（仅有缓存时出题）。
8. 自选题型：设置里勾选启用的复习题型（至少保留一种）。
9. 难度递进题型：间隔短的词出英选中，间隔长的词出中选英/听音。
10. 中选短语题：给出短语中文，四选一英文短语。

## v10 · 算法进阶
1. 记忆保持目标：可选 85/90/95%，相应缩放复习间隔。
2. 间隔随机扰动：间隔 ±5% 抖动，避免同一天复习扎堆。
3. 负荷均衡：某天到期量超过平均 1.5 倍时，把可挪的词前后移 1 天。
4. 逾期加成：逾期很久仍答对的词按实际间隔计算新间隔。
5. 新词自适应：今日到期量过大时建议并可一键减少今日新词。
6. 重学步骤：遗忘的词在之后的复习中先走 1 天 → 3 天的短步骤。
7. 四键模式：可选增加「简单」档，间隔额外 ×1.3。
8. 初始难度拟合：根据历史首答正确率调整新卡初始 ease。
9. 算法说明页：用图表解释每档评分对间隔的影响。
10. 计划模拟器：输入每日新词数，预测 30 天后的每日复习量。

## v11 · 数据与多设备（无云）
1. 合并导入：导入备份时可选「合并」，按最近复习时间合并两台设备的记录。
2. 自动快照：每天自动在本地保存一份快照，保留最近 7 份，可回滚。
3. 加密备份：导出时可设口令（WebCrypto AES-GCM），导入时验证。
4. 学习报告图：一键生成包含总进度、掌握分布、连续天数的长图。
5. 导入词表：从 CSV/TXT 导入单词列表（只保留词库里有的词）生成自定义词单。
6. 数据体检：检测并修复损坏/不存在的单词记录，报告修复数量。
7. 存储管理：显示各类数据占用，可清理例句缓存与发音缓存。
8. 多学习档案：同一设备可建多个档案，互相独立切换。
9. 词单链接：把词单编码进链接 hash，对方打开即可导入（不经服务器）。
10. 剪贴板备份：备份可复制为文本/从剪贴板粘贴恢复。
